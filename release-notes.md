###   BREAKING CHANGES

* **mcp:** cmd/vmafx-mcp is env/config only; the --transport / --port CLI flags are removed (VMAFX_MCP_TRANSPORT / VMAFX_MCP_HTTP_ADDR).
* **operator:** cmd/vmafx-operator is env/config only (CLI flags removed); VMAFX_OPERATOR_PROBE_ADDR -> VMAFX_OPERATOR_HEALTH_PROBE_ADDR, VMAFX_OPERATOR_LEADER_ELECT -> VMAFX_OPERATOR_LEADER_ELECTION, VMAFX_OPERATOR_LOG_LEVEL -> VMAFX_LOG_LEVEL.
* **node:** cmd/vmafx-node is env/config only; the listen address moves from VMAFX_NODE_ADDR to VMAFX_GRPC_LISTEN (:50052 default preserved).
* **server:** cmd/vmafx-server is env/config only (CLI flags removed); VMAFX_PORT/VMAFX_GRPC_PORT replaced by VMAFX_HTTP_ADDR/VMAFX_GRPC_LISTEN.
